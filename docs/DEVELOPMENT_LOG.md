# HutaoChatCore 开发日志

本文件记录已经进入源码并经过验证的开发工作。运行输出仍保存在 `logs/`，两者用途不同：开发日志用于版本审查，运行日志用于故障诊断。

## 2026-08-29：官网动态交互与 DeepSeek 协作入口

### 已完成

- 官网保留 Three.js 粒子场、GSAP 首屏和滚动 reveal，在此基础上增加页面滚动进度、滚动后收缩导航、当前章节高亮和返回顶部交互。
- 将静态认知处理列表改为可点击、键盘可聚焦、自动轮播的交互链路；每一步提供真实处理说明和展开/收起反馈。
- 桌面端卡片继续支持指针倾斜和局部光照，触屏设备自动关闭倾斜，减少动态偏好下关闭自动轮播和非必要动画。
- 通过本机 DeepSeek Harness 的 `Graduation-Project` 工作区建立真实协作会话“为官网交互契约补充测试”。
- DeepSeek Harness 只负责补充 `tests/test_public_site.py` 中的构建产物契约测试；Codex 负责交互实现、视觉验证、改动复核和 Git 交付。
- Harness 任务明确禁止读取 `.env`、修改生产代码、提交或推送 Git。它的测试修改经 Codex 独立复核后保留。

### 验证

- `npm.cmd run build`：通过；Vite 生产资源已更新。
- `python -m pytest -q -p no:cacheprovider tests/test_public_site.py`：7 项通过，其中 4 项由 DeepSeek Harness 补充。
- Edge + Playwright：1440x900 与 390x844 均无横向溢出、无控制台错误；章节高亮、第三个认知步骤展开和返回顶部按钮均可操作。
- `git diff --check`：通过，仅有 Windows 下 Git 的 LF/CRLF 提示。

### 已知事项

- Three.js 动态模块的生产包约 705 KB，Vite 会给出大于 500 KB 的体积提示；模块按需加载，不阻塞首屏 React 主包。
- DeepSeek Harness 可以承担严格限定的源码子任务，但不能自行提交或推送；其输出必须经过 Codex 本地构建、浏览器验证和测试后才能采用。

## 维护规则

- 每次开发在提交前新增一条日期记录，内容必须与实际源码和测试一致。
- 不把 `.env`、令牌、密码、邮箱验证码、用户对话内容或模型输入全文写入开发日志。
- 每个可交付开发批次使用独立 Git 分支和提交，并提供可复制的 PR 标题、正文和验证结果。
- 未通过本地验证的内容标记为“计划”或“已知问题”，不能写成“已完成”。
