# 00 汇总：智能体架构研究与实验计划总表

> 本文件是 T1-T6 六份研究报告的汇总与决策入口。所有结论来自本地研究文档（docs/research/agent-architecture/01-06），均与代码核对并附来源链接。
> **上传门禁：本目录与据此产生的任何实验代码，在实验完成并通过验收前，一律不上传 GitHub（DyQcml12/HeadCore）。**

## 1. 架构定位结论（T1）

HeadCore 相对 2025-2026 主流框架（LangGraph/Agents SDK/AutoGen/CrewAI/MetaGPT/Letta/CoALA/MCP/Dify）的定位：**不是编排框架，而是带人格边界的认知运行时**。

**最强的 3 点（主流框架普遍缺的）**
1. 单一 Self 与关系边界是本地代码而非 Prompt（blocked 用户根本不进模型调用）；
2. 证据边界贯穿全链路（断言必须带来源与置信度，模型自述不能自证）；
3. fail-closed 全本地门禁 + 高测试密度（816 用例）。

**最该补的 3 个缺口**
1. 无结构化工具调用循环（ReAct 缺失，世界工具只能模型调用前一次性前置收集）——建议受限 USE_WORLD_TOOL 白名单循环；
2. 反思循环浅且非学习性（规则 marker 版，无跨会话程序性沉淀、无 LLM 自我批评层）；
3. 观察-行动循环不可恢复、不可编排（主链路硬编码直线，无 checkpointer/interrupt）。

## 2. 运行可靠性：最严重的 5 个失败模式（T2）

1. **流式中断无标记**：断流时半截文本直接结束，客户端分不清"说完"与"断了"；
2. **流式主路径绕过评估门**：Desk 默认流式直通，30+ 条规则门只记录不拦截；
3. **静默截断**：模型流中段错误被当成正常结束并完整落库；
4. **最坏延迟无界**：90s 超时 × 重试 × 修复再生成，一条回复可耗 3 分钟以上；
5. **存储层线性劣化**：MySQL 每查询新建连接（无池）+ JSONL 全量读改写。

P0 实验：E1 流式结束/中断标记（done/truncated 帧）、E2 流式首尾门禁（首段过 evaluator、结尾过自伤/身份门）、E3 静默截断改显式错误、E4 延迟预算（首字超时 + 总预算 + 修复路由上限）。

## 3. 网页端存储结论（T3）

| 数据 | 存储引擎 | 说明 |
| --- | --- | --- |
| 账号/密码 | 关系库（Postgres 或 MySQL V2 二选一） | Argon2id 哈希（现状已正确）；禁止 SQLite/JWT 无状态 |
| 邮箱验证码/会话/重置码 | 同一关系库 | 只存 SHA-256 哈希、一次性消费、改密撤销全会话（现状已正确） |
| 人格 | 代码注册表=运行权威；DB=版本/绑定/审计 | 维持现状分层，不反转 |
| 短期上下文 | 进程内派生 + 关系库最近 N 条 | 建议 N/字数上限配置化；单实例不需要 Redis |
| 长期结构化记忆 | 关系库（真相源） | 保留/撤销/审计；需补过期硬删除任务 |
| 语义记忆 | Qdrant（可重建派生索引） | outbox 最终一致（现状已正确） |
| 审计/限流 | 关系库 | 限流建议加进程内回退实现 |

**最大问题**：网页账号体系 Postgres 与 MySQL V2 "双轨并存"——必须强制单一网页主库并禁止混写。最小改动 5 条与迁移顺序见 03 报告第 9-10 节。

## 4. 视觉设计结论（T4）

**推荐路线**：以"本地受限标签 + 场景状态机"为主线；本地小 VLM（SmolVLM2-2.2B / Qwen2.5-VL-3B-INT4）只做显式触发、限流、单帧快照的可插拔问答层；云 VLM 永不默认启用。

**关键发现**：现有标签层是"断开的传感器"（attention.py 无调用者、router 丢弃观察结果、ChatService 对视觉零引用）。**P0 不是引 VLM，而是把标签层接进对话证据链**（环形缓冲 + VisionContextProvider）。

## 5. 世界模型结论（T5）

**可弥补（工程证据层）**：外部事实校准（来源/有效期/许可门）、结构化世界状态与时间延续（实体-关系-事件图）、不确定性与审计（冲突标记/留痕）——项目已有地基，按 R1-R4 升级（时间衰减→反事实推演→证据自动校准→评估闭环）。

**不可弥补（诚实边界）**：具身因果干预（只能读因果文字，不能做实验）、主观体验（解释鸿沟）、常识默会地基（文本共现的统计投影）。世界模型只能把差距"缩小到最小"，不能"模仿"人的思维。

## 6. 伪自我意识结论（T6）

机制包 5 组件（默认全关、零回归）：a) 持久自我档案 head_self_profile；b) 会话开头自我投影（档案缺失输出空串）；c) 脱机低频反思循环；d) 自我一致性门禁（轻微只审计、严重进 REPAIR，永远让位于自伤/边界/撤销门）；e) 时间感（last_session_at）。

**伦理红线**：不宣称真实意识/情感/权利；不欺骗用户（档案可查看可重置、修订留审计）；安全与边界门禁永远优先；遵守《生成式人工智能服务管理暂行办法》《未成年人网络保护条例》与深度合成标识义务。

## 7. 实验优先级总排序（跨方向合并）

**P0（低成本高收益，可先做）**：T2-E1/E2/E3/E4（流式可靠性+延迟预算）、T3-改1/2/3（网页主库校验、上下文窗口配置化、限流回退）、T4-P0（视觉接线实验）、T6-L0（自我档案，纯增量）。

**P1（中等成本）**：T1-工具循环（受限 USE_WORLD_TOOL）、T5-R1（时间衰减/信念强度）、T3-改4（过期清理脚本）、T4-P1（场景状态机）、T6-L1/L2（投影+一致性门禁）。

**P2+（需真机/真模型验收）**：T4-P2（本地 VLM 基准）、T1-反思层、T5-R2/R3、T6-L3（反思脚本）。
