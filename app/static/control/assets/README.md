# Control Center Assets

`control-atmosphere.webp` is a locally optimized copy of an Unsplash photograph
used as a low-contrast decorative background in the HeadCore control center.

- Source: https://unsplash.com/photos/4e9042af9f23
- Download endpoint: https://images.unsplash.com/photo-1518709268805-4e9042af9f23
- License: https://unsplash.com/license

The UI does not load this asset from an external host at runtime.
